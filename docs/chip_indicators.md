# 籌碼面指標說明

## 指標層級與邏輯

```
時間軸（由慢到快）：

集保股權分散 (週) -> 三大法人現貨 (日) -> 外資期貨未平倉 (日)
-> 借券賣出 (日) -> 融資融券 (日) -> OBI/VPIN/TI (秒級)
```

## 各指標解釋

### 1. 外資期貨未平倉口數
- **資料頻率**：T+1 盤後
- **意義**：外資在台指期的淨部位，是最強的前瞻指標
- **邏輯**：外資先建期貨倉位，再執行現貨，期貨領先現貨 1~3 日
- **權重**：35%

### 2. 三大法人現貨買賣超
- **資料頻率**：T+1，收盤後 15:30
- **意義**：外資、投信、自營商的現貨方向
- **邏輯**：外資連續淨買 = 趨勢確立；投信買超 = 中期支撐
- **權重**：30%

### 3. 集保股權分散表（大戶 vs 散戶）
- **資料頻率**：每週六更新
- **意義**：千張以上大戶持股比例 vs 1~10 張散戶比例
- **邏輯**：大戶比例上升 = 籌碼集中 = 拉抬容易；散戶比例上升 = 股票流入弱手
- **權重**：15%

### 4. 借券賣出餘額
- **資料頻率**：T+1
- **意義**：機構借股票來放空
- **邏輯**：借券大量增加 = 機構預期股價下跌，強力偏空信號
- **權重**：12%

### 5. 融資餘額（反指標）
- **資料頻率**：T+1
- **意義**：散戶用槓桿買股
- **邏輯**：融資快速增加 = 散戶瘋狂追漲 = 主力出貨機會，偏空（反向使用）
- **權重**：8%

## 複合分數計算

```python
chip_score = (
    futures_signal    * 0.35 +
    institutional     * 0.30 +
    whale_score       * 0.15 +
    lending_signal    * 0.12 +
    margin_signal     * 0.08
)
```

## 雙層訊號架構

```
[Layer 1 - 籌碼偏向]  每30分鐘更新
  chip_score > +0.1  -> 今天偏向做多
  chip_score < -0.1  -> 今天偏向做空
        |
        v
[Layer 2 - 微結構時機]  即時 tick 更新
  OBI + TI 方向一致 + VPIN 未超標
        |
        v
  [下單]
```

## 注意事項

1. 所有籌碼指標都是 T+1，今天看的是昨天的資料
2. 籌碼只決定「偏向」，不決定「時機」，時機由微結構決定
3. 大台指期外資部位可以反映整體市場方向，個股要再看個股本身的法人資料
4. 融資是反指標，要反向解讀
